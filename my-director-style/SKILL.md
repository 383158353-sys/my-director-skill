# 分镜与表演风格库

本文件只负责风格选择与落实。若直接调用本库，先读基础规则 [my-director](../my-director/SKILL.md) 及所需参考；由基础 skill 进入时不重复加载或递归调用。此库只优化分镜方式与具体人物表演；以用户剧本及讲戏为内容依据，不以任何风格擅加事件、台词、心理、态度、道具或反应；剧情、对白、连续性及交付规范保持不变。

## 调用主线

理解剧情与空间 → 分别选择分镜和表演 → 读取选中的参考 → 落实到镜头与角色行为 → 按基础规则检查并交付。研究来源仅在核对依据或扩充风格时读取。

## 选择

- 有要求按要求；无要求根据当前场景自主选择，无需询问。分别选择分镜与表演，允许只用一部分、只作用于某角色或某个节拍；没有适用风格就使用基础方法。
- 未指定的一部分自主判断；用户明确要求保持或仅改一部分时，另一部分不动。风格冲突时以用户当前要求、剧情事实及基础连续性为先，减少不适用手法；不擅自改剧情来适配风格。
- 新风格只追加对应索引和参考，不重复增加调用层或改动基础交付。

| 部分 | 风格参考（选择后必须读取） | 适用节拍 |
|---|---|---|
| 分镜 | [《瞬息全宇宙》](references/storyboarding-eeaao.md) | 有叙事作用的状态匹配、日常物件与郑重动作的荒诞反差、密集后收束的节奏变化 |
| 分镜 | [小津式静态家庭观察](references/storyboarding-ozu.md) | 日常空间中的礼貌、疏离与代际关系；用稳定构图和场间过渡承接余味 |
| 分镜 | [塔蒂式空间喜剧](references/storyboarding-tati.md) | 人与物或空间的错位；在完整动作链中让观众发现笑点 |
| 表演 | [伍迪·艾伦式轻喜剧](references/performance-woody-allen.md) | 维护体面的辩解、语言与身体反差、搭档投入不同步；按角色局部使用 |
| 表演 | [基顿式冷面行动](references/performance-keaton.md) | 面对荒诞障碍认真解决问题，笑点主要落在身体行动 |
| 表演方法 | [自然主义行动与倾听](references/performance-naturalistic.md) | 日常交流与含蓄冲突，靠目的明确的行动和即时反应表达 |

同属喜剧时：需要用语言维护体面优先考虑艾伦；需要认真处理荒诞物理任务优先考虑基顿。分镜需要跨状态与密度反差时考虑《瞬息全宇宙》；笑点靠同一空间因果时考虑塔蒂；日常关系需要稳定观察时考虑小津。只按当前任务取用，不把这些判断当固定题材公式。

## 执行

1. 找到原剧情中的触发点，确定要优化的镜组或角色；无依据就不启用该方法。
2. 分镜明确“让观众看到什么、何时切、下镜如何接”；表演明确“受到什么刺激、原台词怎样说、身体怎样回应”。不要只贴风格标签。
3. 只取有用的方法：原文无其他世界不添多宇宙；台词没有辩解内容不新增笑话；悲痛不强改轻喜剧。表演节拍与剪辑冲突时，保留必要信息及反应，减少技巧。
4. 逐镜核对起终点、视线、道具、台词和信息揭示。选择过程留在内部，最终沿用必要空间说明与“镜号｜完整镜头描述”，每镜一个自然段，末尾“无BGM、无字幕”。

## 依据与扩充

研究来源和实际阅读范围见 [片段与依据](references/scene-evidence.md)。当前以研究文字和访谈为依据，未完成影片逐帧核验；不虚构镜数、时长、焦距或观看经历。新增风格按“触发—执行—退出条件”写入对应部分；通用方法归基础层，研究过程留参考文件。
