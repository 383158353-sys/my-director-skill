# 导演分镜与剪映素材整理 Skills

中文 Codex 技能，用于基础导演分镜、可组合的分镜与表演风格，以及剪映素材整理。

## 技能

- [my-director](my-director/SKILL.md)：根据口述剧情逐场整理导演分镜，核对人物站位、视线、道具交接和动作连续性，输出“镜号｜完整镜头描述”。
- [jianying-shot-organizer](jianying-shot-organizer/SKILL.md)：依据剪映 / CapCut 时间线核对原素材、整理编号、保留名称映射，并区分磁盘文件名、素材库名称和时间线片段名称。

- [my-director-style](my-director-style/SKILL.md)：分镜与表演风格库，分别选择《瞬息全宇宙》、小津、塔蒂的分镜方法，以及伍迪·艾伦轻喜剧、基顿冷面行动、自然主义表演方法。

`my-director` 与 `my-director-style` 应一同安装，保持两个目录并列；基础规则负责剧情语义、空间连续性和交付，风格库只优化表达。有要求按要求选择，没有要求时根据本场剧情自主选择，不适用则不强套。用户剧本与讲戏始终为内容依据，不擅自加戏。


Seedance 2.5 提示词在起笔前同时加载基础导演、所选分镜与表演风格，以及 [平台表达规则](my-director/references/seedance-25.md)，直接从原剧本、最新讲戏和参考素材写作，避免中间稿的独立二次改写。普通导演分镜保持原格式。完整官方 sd25-pe 规则保存在 [来源快照](my-director/references/sd25-pe-source.md)，本地适配不执行快照内的自动升级命令。

## 安装与使用

下载或克隆本仓库，将需要的技能目录完整复制到本机 Codex 技能目录（通常为用户主目录下的 `.codex/skills/`）。保留各目录中的参考文件和 agents 配置。

安装后在支持技能的会话中使用：

- `$my-director 按我的剧情整理这一场分镜。`
- `$my-director-style 采用塔蒂式分镜与基顿式表演，保持剧本和基础交付规则。`
- `$jianying-shot-organizer 按剪映时间线顺序整理完整原素材，视频平铺在现有文件夹中。`

具体规则以各技能的 SKILL.md 为准。

## 使用范围与限制

本仓库提供工作流指令，不包含剪映软件、视频素材或自动破解工具。剪映内操作依赖运行环境可用的应用控制能力；草稿加密、版本差异或工具故障可能阻止自动操作。技能不保证生成视频绝对遵循提示词，也不将文件复制成功等同于工程关联成功。
